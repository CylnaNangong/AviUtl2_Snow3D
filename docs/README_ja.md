> ❄️ **AviUtl ExEdit2 用「真・3D」雪パーティクル・カスタムオブジェクト** —— 数千片の雪が本物の 3D 空間を舞い、建物やキャラクターに正しく遮蔽されます。

## 1. 概要・主な特徴

AviUtl2 の 3D カメラ空間に**本物の三次元降雪**をシミュレートします：

- **真 3D パーティクル**：最大 4000 片が独立した 3D 位置・速度・重力・風・揺れ（sway）を持ち、カメラを回しても透視関係が完全に正しい平面パーティクル疑似ではありません。
- **ハードウェア深度遮蔽**：粒子を 3D ジオメトリとして描画するため人物・建物との前後遮蔽が自然に発生。ソフトエッジとサイズ分散で近景のボケも自然です。
- **スマート発生領域**：発生ボックスはカメラ追従（`カメラに追従`）または世界座標固定（`世界座標に固定`）。画面に必要な範囲を自動包裹し壁を画面外へ押し出す（`壁を画面の外へ`）ので、画面内には常に雪・画面外に粒子を無駄遣いしません。
- **寿命とフェード**：生存時間による自然な出現・消滅で「一斉落下」の機械感を排除。
- **純スクリプト・依存ゼロ**：プラグイン不要、D&D するだけ。

| 項目 | 要件 |

| 本体 | AviUtl ExEdit2 `v2.1.15` 以上（ＫＥＮくん公式・別途入手） |
| OS | Windows（Direct3D 11） |
| その他 | プラグイン不要 |

## 3. 導入方法（`.au2pkg.zip` D&D 対応）

1. **`Snow3D-v1.22.au2pkg.zip`** をダウンロード；
2. zip を **AviUtl2 ウィンドウにドラッグ**するだけで導入完了；
3. 手動導入：`Script/雪（3D）.obj2` と `Language/*.aul2` を `C:\ProgramData\aviutl2\Script\`・`Language\` へ。

## 4. 基本的な使い方

1. 任意のレイヤーに「**雪（3D）**」カスタムオブジェクトを追加（人物より奥・背景より手前が推奨）；
2. 既定値で一般的な自然な降雪。吹雪は「粒子数」と「粒径」を上げ、細雪は「粒径」を下げて「エッジのぼかし」を上げます；
3. 「カメラ制御」があるなら「カメラに追従」を ON に。固定カメラでは「世界座標に固定」を。

## 6. 互換性について

- 本スクリプトは 100% 公式 Lua API（`obj.drawpoly` 等）のみで動作し、ホスト内部構造へのアクセスやメモリ探針に依存しません——**公式更新で失效しません**。
- 「体積光（3D）」「VolumetricFog3D」と同一シーンで併用可能（体積光 v3.07+ は雪レイヤーを遮蔽候補から自動除外）。
